REST API Endpoints Overview
  • GET /api/dashboard — Returns high-level metrics & trends
  • GET /api/tickets — Searchable & paginated ticket dataset
  • POST /api/miner/cluster — Executes KMeans or DBSCAN demand mining
  • GET /api/benchmarks/run — Runs model precision/recall/F1 benchmarks
  • POST /api/edge-cases/simulate — Triggers edge case resilience suite
  • POST /api/workflow/toggle — Switch between AI & Legacy workflows
  • POST /api/workflow/rollback — Zero-data-loss rollback to legacy
  • GET /api/reports/download/<type>/<format> — Exports PDF or CSV reports
User & Service Manager Guide
  1. Dashboard: Monitor live KPIs, resolution rates, and top recurring demand clusters.
  2. Ticket Management: Log new tickets, edit/delete records, or batch-import CSV files.
  3. Demand Miner: Adjust algorithm parameters (KMeans vs DBSCAN) and execute text clustering to uncover root cause clusters.
  4. Permanent Fixes: Review ranked Problem Management solutions with projected time and cost savings.
  5. Stakeholder Feedback: Submit Service Manager evaluations and track approval metrics.
