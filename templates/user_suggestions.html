Slow VDI / Desktop Session
Application & Remote Desktop

VDI profile disk IOPS saturation is the top cause of slow login times during peak 9 AM hours.

Recommended Self-Fix: Clear local temp files (%temp%), log off VDI cleanly instead of disconnecting, and ensure local network latency is < 40ms.
Active Directory Password Lock
Access & Identity

Expired mobile mail sync credentials often trigger repetitive AD account lockouts.

Recommended Self-Fix: Update Exchange mail password on mobile devices first before unlocking account on Okta portal.
VPN Connection Dropping
Network Operations

RADIUS authentication timeout occurs every 45 minutes on older GlobalProtect client builds.

Recommended Self-Fix: Upgrade GlobalProtect client to v5.3.1 from Software Center and click Refresh Connection.
Outlook Mailbox Full Warning
Application & Storage

Mailboxes reaching 10GB reject incoming attachments over 10MB.

Recommended Self-Fix: Empty Deleted Items folder and run Clean Up Mailbox → Archive Items older than 30 days.
